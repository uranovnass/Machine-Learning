# Pipeline предобработки данных

## Описание

В данной практической работе был собран pipeline предварительной обработки данных для задачи классификации.

Используется **Breast Tissue Dataset**, содержащий измерения с 9 числовыми признаками и целевой переменной `Class`.

Основная цель работы — подготовить данные к машинному обучению, корректно обработать возможные пропуски, разделить признаки по типам и избежать утечки данных между обучающей и тестовой выборками.

---

## 1. Структура данных

Целевая переменная:

* `Class`

Числовые признаки:

* `I0`
* `PA500`
* `HFS`
* `DA`
* `Area`
* `A.DA`
* `Max.IP`
* `DR`
* `P`

Категориальных входных признаков в датасете нет.

Таким образом:

* количество входных признаков — **9**;
* количество категориальных признаков — **0**.

---

## 2. Проверка пропущенных значений

Перед созданием pipeline была выполнена проверка пропусков.

Результат:

* `I0` — 0
* `PA500` — 0
* `HFS` — 0
* `DA` — 0
* `Area` — 0
* `A.DA` — 0
* `Max.IP` — 0
* `DR` — 0
* `P` — 0

Общее количество пропущенных значений:

**0**

Таким образом, в текущем датасете отсутствуют пропуски.

Несмотря на это, в pipeline предусмотрена обработка возможных пропусков для повышения устойчивости preprocessing при работе с новыми данными.

---

## 3. Стратегия обработки признаков

### Числовые признаки

Для числовых признаков используется следующая последовательность:

1. Заполнение пропусков медианой.
2. Стандартизация признаков с помощью `StandardScaler`.

Медиана выбрана вместо среднего значения, поскольку она менее чувствительна к выбросам. Для числовых измерений такой подход является более устойчивым при наличии отдельных аномальных значений.

В текущем датасете пропусков нет, поэтому фактическое заполнение значений не выполняется.

### Категориальные признаки

Для категориальных признаков предусмотрена отдельная обработка:

1. Пропуски заменяются отдельной категорией `missing`.
2. Категориальные значения преобразуются в числовой формат с помощью `OneHotEncoder`.

В текущем датасете категориальные признаки отсутствуют, поэтому эта часть pipeline фактически не используется.

---

## 4. Train/Test разделение

Данные были разделены на обучающую и тестовую выборки:

* `X_train` — **84 × 9**
* `X_test` — **22 × 9**

Использовалось разделение:

* 80% — training set;
* 20% — test set.

Для сохранения распределения классов использовался параметр `stratify`.

---

## 5. ColumnTransformer

Для объединения разных стратегий обработки был использован `ColumnTransformer`.

Структура preprocessing:

```text
ColumnTransformer
│
├── Numerical features
│   ├── SimpleImputer(strategy="median")
│   └── StandardScaler()
│
└── Categorical features
    ├── SimpleImputer(strategy="constant",
    │                  fill_value="missing")
    └── OneHotEncoder(handle_unknown="ignore")
```

Поскольку все входные признаки являются числовыми, фактически используется числовая ветка.

---

## 6. Проверка отсутствия Data Leakage

Для предотвращения утечки данных preprocessing обучается только на тренировочной выборке.

Для `X_train` используется:

```text
fit_transform()
```

На этом этапе рассчитываются параметры обработки на основе только тренировочных данных.

Для `X_test` используется:

```text
transform()
```

Тестовая выборка не используется для обучения preprocessing.

Таким образом, информация из тестовой выборки не влияет на параметры заполнения пропусков или стандартизации.

## 9. Вывод

В результате был создан pipeline предварительной обработки данных.

Все входные признаки были классифицированы как числовые. Для них предусмотрено заполнение возможных пропусков медианой и стандартизация.

Также была создана отдельная ветка для категориальных признаков, хотя в текущем датасете такие признаки отсутствуют.

Preprocessing был обучен только на тренировочной выборке и затем применён к тестовой, что позволяет избежать Data Leakage.

Полученные размеры данных подтверждают корректность обработки:

**Train: 84 × 9 → 84 × 9**

**Test: 22 × 9 → 22 × 9**
