# Практическая работа № 6. Классификация текстов

## Цель работы

Освоить основные этапы обработки текстовых данных и построить классификатор на основе TF-IDF и наивного байесовского алгоритма.

## Датасет

**IMDb Dataset of 50K Movie Reviews**

Источник: [Kaggle — IMDb Dataset of 50K Movie Reviews](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)

Датасет содержит около 50 000 отзывов о фильмах с двумя классами тональности: `positive` и `negative`.

Используемые столбцы:
- `review` — текст отзыва;
- `sentiment` — метка тональности.

## Выполненные задания

### 1. Предобработка текста

Реализована функция `clean_text()`, выполняющая:
- приведение текста к нижнему регистру;
- удаление HTML-тегов;
- удаление пунктуации и цифр;
- токенизацию;
- удаление стоп-слов с сохранением значимых отрицаний.

### 2. Разделение данных

Данные разделены на обучающую и тестовую выборки в соотношении 80:20. Использованы `train_test_split`, `random_state=42` и `stratify` для сохранения пропорций классов.

### 3. Векторизация TF-IDF

Для преобразования текстов в числовые признаки использован `TfidfVectorizer` со следующими параметрами:
- `min_df=5`;
- `max_df=0.9`;
- `max_features=10000`.

Векторизатор обучается только на обучающей выборке, что позволяет избежать утечки данных.

### 4. Обучение модели

Использован алгоритм `MultinomialNB` — наивный байесовский классификатор.

Модель обучена на TF-IDF-признаках и использована для предсказания тональности отзывов.

### 5. Оценка качества

Качество модели оценивалось с помощью следующих метрик:
- Accuracy;
- Precision;
- Recall;
- F1-score.

Также построена матрица ошибок для анализа правильных и неправильных предсказаний.

### 6. Анализ ошибок

Рассмотрены пять неправильно классифицированных отзывов. Для каждого примера проанализированы возможные причины ошибки, включая сарказм, отрицания, смешанную тональность, редкие слова и недостаточный учёт контекста.

### 7. Дополнительный анализ

Выведены слова, наиболее характерные для положительных и отрицательных отзывов. Результаты сохранены в CSV-файл `classification_errors.csv`.

## Результаты работы
