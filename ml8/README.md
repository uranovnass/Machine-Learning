# Сравнение моделей классификации

## Описание проекта

В работе рассматривается задача бинарной классификации клиентов по признаку оттока (`churn`).

Для решения задачи используются и сравниваются три алгоритма машинного обучения:

- Logistic Regression;
- Random Forest;
- XGBoost.

Модели обучаются на синтетическом датасете клиентов. Для категориальных признаков используется One-Hot Encoding. Данные разделяются на обучающую и тестовую выборки в соотношении 80/20.

Работа выполнена в **Google Colab**.

## Подготовка данных

Из исходного датасета исключаются:

```python
subscriber_code
```

как идентификатор клиента, и:

```python
churn
```

как целевая переменная.

Целевая переменная:

```text
churn
```

принимает два значения:

- `0` — клиент не ушёл;
- `1` — клиент ушёл.

Данные разделяются с использованием `stratify=y`, чтобы сохранить соотношение классов в обучающей и тестовой выборках. В результате получено:

```text
Train: 2400 объектов
Test: 600 объектов
```



## Предобработка

Категориальные признаки:

- `region`;
- `tariff`.

кодируются с помощью:

```python
OneHotEncoder(handle_unknown="ignore")
```

Остальные признаки передаются дальше без дополнительного преобразования для моделей на основе деревьев.

Для Logistic Regression дополнительно используется `StandardScaler`, чтобы привести числовые признаки к сопоставимому масштабу.

## Метрики

Для оценки моделей используются:

### F1-score

F1-score учитывает одновременно Precision и Recall.

Чем ближе значение к `1`, тем лучше модель балансирует между правильным обнаружением положительного класса и количеством ложных срабатываний.

### ROC-AUC

ROC-AUC показывает способность модели различать два класса.

Чем выше значение, тем лучше модель разделяет клиентов, которые ушли, и клиентов, которые остались.

Также измеряется **время обучения** каждой модели.

## XGBoost

Для XGBoost сначала используется модель:

```python
XGBClassifier(
    n_estimators=300,
    learning_rate=0.05,
    max_depth=4,
    random_state=42
)
```

Полученный результат:

```text
F1 train = 0.789
F1 test  = 0.574
ROC-AUC  = 0.779
```

Время обучения составило около `0.28` секунды.

## Random Forest

Для Random Forest используется:

```python
RandomForestClassifier(
    n_estimators=100,
    random_state=42
)
```

Результат:

```text
F1 train = 1.000
F1 test  = 0.556
ROC-AUC  = 0.752
```

Время обучения — около `0.78` секунды в отдельном эксперименте.

Высокий F1 на обучающей выборке при значительно меньшем результате на тестовой показывает признаки **переобучения**.

## Early Stopping в XGBoost

Отдельно проверяется механизм `early_stopping`.

Используется большое количество деревьев:

```python
n_estimators=2000
```

и:

```python
early_stopping_rounds=50
```

Обучение прекращается, если качество на валидационной выборке перестаёт улучшаться.

В эксперименте лучшая итерация:

```text
108
```

а значение `logloss` на validation:

```text
0.2948
```



Таким образом, early stopping позволяет не обучать модель все 2000 итераций, если дальнейшее обучение уже не улучшает результат.

## Итоговое сравнение

В финальном сравнении получены следующие результаты:

| Модель | F1 train | F1 test | ROC-AUC test | Время |
|---|---:|---:|---:|---:|
| Logistic Regression | 0.594 | **0.611** | **0.806** | 0.10 c |
| Random Forest | 1.000 | 0.556 | 0.752 | 1.91 c |
| XGBoost | 0.645 | 0.586 | 0.792 | 0.51 c |



## Вывод

По результатам эксперимента лучшим вариантом на тестовой выборке стала **Logistic Regression**:

- самый высокий F1 test — `0.611`;
- самый высокий ROC-AUC — `0.806`;
- самое короткое время обучения среди трёх моделей — `0.10` секунды.

Random Forest показал идеальный результат на обучающей выборке (`F1 = 1.000`), но результат на тестовой выборке значительно ниже (`F1 = 0.556`), что указывает на переобучение.

XGBoost показал промежуточный результат: `F1 test = 0.586` и `ROC-AUC = 0.792`.

Таким образом, на данном датасете и при выбранных параметрах **Logistic Regression показала наиболее стабильный результат на тестовой выборке**.
