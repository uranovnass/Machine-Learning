## Датасет

Для работы используется искусственный двумерный датасет `make_moons` из библиотеки Scikit-learn.

Датасет состоит из двух классов, расположенных в форме двух полумесяцев. Такие данные не могут быть хорошо разделены простой прямой линией, поэтому они подходят для демонстрации различий между линейным и нелинейным ядрами SVM.

Количество объектов: **300**

Количество признаков: **2**

Количество классов: **2**

Перед обучением признаки масштабируются с помощью `StandardScaler`.

## Используемые модели

### 1. SVM с линейным ядром

Используется:

```python
SVC(kernel="linear", C=1)
```

Линейное ядро строит прямую разделяющую границу.

Для данных `make_moons` такая граница подходит плохо, поскольку классы имеют нелинейную форму.

### 2. SVM с RBF-ядром

Используется:

```python
SVC(kernel="rbf", C=1, gamma="scale")
```

RBF-ядро позволяет строить нелинейную границу решения.

Поэтому оно лучше подходит для разделения двух полумесяцев.

### 3. RBF с изменённым параметром C

Дополнительно используется:

```python
SVC(kernel="rbf", C=10, gamma="scale")
```

Значение `C` увеличивается с `1` до `10`, чтобы посмотреть, как изменится граница решения.

## Параметр C

Параметр `C` определяет, насколько строго SVM относится к ошибкам классификации.

- Маленькое `C` — модель допускает больше ошибок, граница получается более простой.
- Большое `C` — модель сильнее старается правильно классифицировать обучающие объекты.

Таким образом, увеличение `C` делает модель более строгой.

## Результаты

### Линейное ядро

Линейная модель создаёт практически прямую границу. Она не может хорошо повторить форму двух полумесяцев, поэтому часть объектов классифицируется неправильно.

### RBF-ядро

RBF-модель создаёт нелинейную границу, которая лучше соответствует форме данных. Поэтому качество классификации значительно выше.

### Влияние C

При увеличении `C` с `1` до `10` граница решения становится более ориентированной на правильную классификацию обучающих объектов.

## Ответы на вопросы

### Какое ядро лучше разделило данные и почему?

Лучше данные разделило **RBF-ядро**. Линейное ядро строит прямую границу и поэтому плохо подходит для данных в форме двух полумесяцев. RBF-ядро позволяет создавать нелинейную границу и лучше разделяет классы.

### Как изменение C повлияло на границу?

При увеличении `C` классификатор становится более строгим к ошибкам на обучающей выборке. Граница решения сильнее подстраивается под обучающие данные. При слишком большом `C` существует риск переобучения.
