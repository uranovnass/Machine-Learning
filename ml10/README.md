# Практическая работа №10. Кластеризация и сегментация данных

## Описание

В данной практической работе исследуется задача обучения без учителя на датасете **MNIST** с использованием алгоритма **K-Means**.

Цель работы — выполнить кластеризацию изображений рукописных цифр, определить подходящее количество кластеров с помощью нескольких критериев, интерпретировать полученные сегменты и проверить устойчивость результата.

---

## Цель работы

- применить метод обучения без учителя;
- выполнить кластеризацию данных с помощью K-Means;
- определить оптимальное количество кластеров;
- использовать метод локтя;
- рассчитать коэффициент силуэта;
- построить профили кластеров;
- содержательно интерпретировать полученные кластеры;
- проверить устойчивость кластеризации при изменении `random_state`.

---

**MNIST Test Dataset**

/content/sample_data/mnist_test.csv

## Подготовка данных

Так как CSV-файл не содержал названий столбцов, он был загружен с параметром:

```python
pd.read_csv(path, header=None)
```

После загрузки данные были разделены:

```python
y = df.iloc[:, 0]
X = df.iloc[:, 1:]
```

В результате:

```text
X: 10000 × 784
y: 10000
```

`X` содержит только пиксели изображений.

---

## Масштабирование

Перед кластеризацией признаки были стандартизированы с помощью `StandardScaler`.

```python
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
```

Это необходимо для того, чтобы признаки имели сопоставимый масштаб.

---

## Уменьшение размерности

Исходные изображения содержат 784 признака. Для ускорения кластеризации и уменьшения размерности был применён метод главных компонент **PCA**.

Количество компонент:

```text
50
```

Использованный код:

```python
pca = PCA(n_components=50, random_state=42)
X_pca = pca.fit_transform(X_scaled)
```

В результате данные были преобразованы из:

```text
10000 × 784
```

в:

```text
10000 × 50
```

# Определение количества кластеров

Для определения количества кластеров были использованы два критерия:

1. метод локтя;
2. коэффициент силуэта.

Исследовались значения:

```text
k = 2 ... 10
```

---

## Метод локтя

Для каждого значения `k` рассчитывалась инерция K-Means.

По графику видно, что наиболее выраженный перелом кривой наблюдается примерно при:

```text
k = 4
```

После `k=4` уменьшение инерции становится более плавным.

Поэтому метод локтя указывает на использование примерно **4 кластеров**.

---

## Коэффициент силуэта

Для тех же значений `k` был рассчитан Silhouette Score.

Максимальное значение получилось при:

```text
k = 2
Silhouette Score ≈ 0.15
```

Однако два кластера дают слишком грубое разделение изображений MNIST.

Поэтому с учётом содержательной интерпретируемости кластеров было принято решение использовать:

```text
k = 4
```

# Устойчивость кластеризации

Для проверки устойчивости алгоритм K-Means был повторно запущен с:

```text
random_state = 123
```

Размеры новых кластеров:

| Кластер | Количество объектов |
|---|---:|
| 0 | 3291 |
| 1 | 2460 |
| 2 | 894 |
| 3 | 3355 |

Номера кластеров изменились, однако сами группы в основном сохранились.

Соответствие кластеров:

| `random_state=42` | `random_state=123` |
|---|---|
| Кластер 0 | Кластер 1 |
| Кластер 1 | Кластер 3 |
| Кластер 2 | Кластер 0 |
| Кластер 3 | Кластер 2 |

Для количественной оценки устойчивости использовался **Adjusted Rand Index**.

Полученный результат:

```text
ARI = 0.9404
```

Высокое значение показывает, что результаты двух запусков очень похожи, несмотря на изменение `random_state`.

# Вывод

В ходе практической работы была выполнена кластеризация изображений рукописных цифр MNIST методом K-Means.

Перед кластеризацией признаки были стандартизированы, а размерность данных уменьшена с 784 до 50 компонент с помощью PCA.

Для выбора количества кластеров были использованы метод локтя и коэффициент силуэта. Метод локтя показал выраженный перелом примерно при `k=4`, тогда как максимальный коэффициент силуэта был получен при `k=2`. С учётом содержательной интерпретируемости сегментов было выбрано **4 кластера**.

Полученные кластеры имеют различный состав. Один из них особенно хорошо выделяет изображения цифры 0 — её доля составляет **67.31%**. Остальные кластеры являются более смешанными и объединяют цифры с похожими визуальными формами.

Повторная кластеризация с другим `random_state` дала **Adjusted Rand Index = 0.9404**, что свидетельствует о высокой устойчивости полученного разбиения.

Таким образом, K-Means позволил выделить содержательно различимые группы изображений MNIST без использования целевой разметки при обучении.
