# Breast Tissue Dataset — Exploratory Data Analysis

## 1. Описание проекта

В данной работе проведён исследовательский анализ данных (EDA) набора **Breast Tissue Dataset**.

Набор данных содержит числовые измерения различных образцов тканей. Основная задача — изучить структуру данных, найти закономерности, проверить качество данных и подготовить их для дальнейшего использования в задаче классификации с помощью машинного обучения.

> Важно: данный анализ не является медицинской диагностикой. Он используется для изучения данных и подготовки к построению модели классификации.

---

## 2. Dataset

Источник данных: **UCI Machine Learning Repository — Breast Tissue Dataset**

Размер набора данных:

- 106 наблюдений
- 10 столбцов
- 9 числовых признаков
- 1 целевая переменная `Class`
- 6 классов

### Классы

- `adi` — Adipose
- `car` — Carcinoma
- `fad` — Fibro-adenoma
- `gla` — Glandular
- `mas` — Mastopathy
- `con` — Connective

### Признаки

| Признак | Описание |
|---|---|
| `I0` | Impedivity at zero frequency |
| `PA500` | Phase angle at 500 KHz |
| `HFS` | High-frequency slope |
| `DA` | Impedance distance between spectral ends |
| `Area` | Area under the spectrum |
| `A.DA` | Area normalized by DA |
| `Max.IP` | Maximum of the spectrum |
| `DR` | Distance between I0 and real part of maximum-frequency point |
| `P` | Length of the spectral curve |

Измерения связаны с электрическими характеристиками образцов тканей на различных частотах.

## 3. Цель EDA

Основные цели анализа:

1. Изучить структуру и типы данных.
2. Проверить наличие пропущенных значений.
3. Проверить наличие дубликатов.
4. Проанализировать распределение числовых признаков.
5. Найти потенциальные выбросы.
6. Изучить асимметрию распределений.
7. Исследовать корреляции между признаками.
8. Проанализировать распределение целевых классов.
9. Подготовить данные для дальнейшего машинного обучения.
