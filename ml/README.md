## 1. Описание проекта

Проект посвящён исследовательскому анализу данных (Exploratory Data Analysis, EDA) измерений электрического импеданса образцов ткани молочной железы.

Датасет содержит результаты измерений электрических характеристик свежих образцов тканей на нескольких частотах. Данные используются для изучения различий между типами тканей и исследования информативности числовых признаков.

В рамках проекта выполняются:
- загрузка и первичная проверка данных;
- изучение структуры и типов признаков;
- проверка пропущенных значений;
- расчёт описательной статистики;
- визуализация распределения числовых признаков;
- анализ распределения классов;
- сравнение средних значений признаков между классами;
- формулирование выводов на основе результатов анализа.

**Цель проекта:** изучить структуру датасета, выявить особенности распределения данных и определить, какие различия между классами заслуживают дальнейшего исследования.

| `Class` | Категория образца ткани |
| `I0` | Параметр электрического измерения |

| `HFS` | Признак высокочастотных измерений |
| `DA` | Числовая характеристика измерения |
| `Area` | Площадь, рассчитанная на основе измерительных данных |
| `A.DA` | Дополнительный производный параметр измерений |
| `Max.IP` | Максимальное значение параметра IP |
| `DR` | Дополнительный числовой параметр измерений |
| `P` | Дополнительный числовой параметр измерений |

*Примечание:* названия столбцов сохранены в соответствии с исходным файлом. Для некоторых сокращений требуется сверка с документацией исходного датасета перед использованием в научных интерпретациях.

```python
plt.ylabel("Number of observations")
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
```

### 9.7. Сравнение классов

```python
print("Количество объектов каждого класса:")
print(df["Class"].value_counts())

print("\nДоли классов (%):")
print((df["Class"].value_counts(normalize=True) * 100).round(2))

print("\nСредние значения признаков по классам:")
print(df.groupby("Class").mean(numeric_only=True).round(2))
```

## 10. Результаты первичного анализа

На основе выполненной проверки получены следующие результаты:

- Размер датасета составляет **106 строк и 10 столбцов**.
- Данные включают одну категориальную переменную `Class` и девять числовых признаков.
- В проверенной таблице отсутствуют пропущенные значения.
- Наиболее многочисленный класс — `adi`: 22 объекта, или 20,75%.
- Наименее многочисленный класс — `con`: 14 объектов, или 13,21%.
- Средние значения числовых признаков различаются между классами.

### Наблюдения

1. **Распределение классов.** Датасет включает шесть категорий. Доля класса `adi` составляет 20,75%, а класса `con` — 13,21%. Ни один класс не содержит большинства наблюдений.

2. **Различия по признаку `I0`.** Среднее значение `I0` для класса `adi` составляет 2052,05, тогда как для класса `gla` — 238,32. Это указывает на различие средних значений признака между данными категориями.

3. **Особенности класса `adi`.** Для этого класса наблюдаются высокие средние значения `Area` (24889,74), `Max.IP` (194,60), `DR` (324,71) и `P` (2138,75) по сравнению с большинством других классов. Эти различия могут быть полезны для дальнейшего исследования взаимосвязей между измерениями и категориями тканей.

Указанные наблюдения описывают статистические различия в выборке и сами по себе не доказывают причинно-следственные связи или диагностическую значимость признаков.
