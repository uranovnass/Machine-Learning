# Первичный анализ данных

## Описание

В данном проекте проводится первичный анализ датасета с использованием Python, Pandas, Matplotlib и Seaborn.

## Окружение

Для проекта использовано виртуальное окружение `venv`, поскольку оно встроено в Python и позволяет изолировать зависимости проекта без установки дополнительного менеджера окружений.

## Структура проекта

- `data/` — исходный датасет.
- `notebooks/` — Jupyter Notebook с анализом данных.
- `README.md` — описание проекта.

## Используемые библиотеки

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter
