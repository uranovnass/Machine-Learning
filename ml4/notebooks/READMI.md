# Machine Learning — Variant B

## Описание

В работе выполняется первичный анализ данных и построение модели машинного обучения для классификации объектов по классам.

## Окружение

Для проекта использовано виртуальное окружение venv, так как оно позволяет изолировать зависимости проекта и использовать отдельный набор установленных библиотек.

## Структура проекта

```text
ml4/
├── data/
│   └── data.csv
├── notebooks/
│   └── notebooks.ipynb
├── .venv/
└── README.md
