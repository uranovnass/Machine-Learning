# Практическая работа №4 — Регрессионная модель

## Цель работы

Построить и интерпретировать модель линейной регрессии для прогнозирования стоимости жилья, оценить её качество с помощью метрик регрессии и сравнить модели на полном и сокращённом наборе признаков.

---

## Датасет

В работе используется **California Housing Dataset**.

Данные содержат информацию о жилых районах Калифорнии на основе данных переписи населения 1990 года.

Основные признаки:

- `longitude` — долгота;
- `latitude` — широта;
- `housing_median_age` — медианный возраст жилья;
- `total_rooms` — общее количество комнат;
- `total_bedrooms` — общее количество спален;
- `population` — население района;
- `households` — количество домохозяйств;
- `median_income` — медианный доход;
- `ocean_proximity` — близость к океану;
- `median_house_value` — медианная стоимость жилья.

Целевая переменная:

```text
median_house_value
````

Задача модели — предсказать стоимость жилья на основе характеристик района.

---

## Используемые библиотеки

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

---

## Подготовка данных

Сначала был выполнен первичный анализ датасета:

* определён размер набора данных;
* проверены типы данных;
* проверено наличие пропусков;
* проверены дубликаты;
* изучена статистика числовых признаков.

Для подготовки данных использовался `Pipeline`.

Для числовых признаков:

1. пропуски заменялись медианным значением;
2. выполнялось масштабирование с помощью `StandardScaler`.

Для категориального признака `ocean_proximity`:

1. пропуски заменялись наиболее частым значением;
2. применялось One-Hot Encoding.

Данные были разделены на обучающую и тестовую выборки в соотношении 80/20.

---

## Базовая модель

В качестве базовой модели использовалась `LinearRegression`.

Базовая модель обучалась на всех доступных признаках.

Полученные результаты на тестовой выборке:

| Метрика |      Значение |
| ------- | ------------: |
| MAE     |     50 670.49 |
| MSE     | 4 908 291 000 |
| RMSE    |     70 059.19 |
| R²      |        0.6254 |

### Интерпретация

**MAE = 50 670** означает, что модель в среднем ошибается примерно на 50,7 тысяч единиц стоимости жилья.

**RMSE = 70 059** показывает типичный размер ошибки с учётом более крупных ошибок и составляет около 70,1 тысяч единиц стоимости.

**R² = 0.6254** означает, что модель объясняет примерно 62,5% вариации стоимости жилья на тестовой выборке.

---

## Анализ мультиколлинеарности

Для анализа взаимосвязи между числовыми признаками была построена корреляционная матрица.

Были обнаружены сильные корреляции:

* `total_bedrooms` и `households` — **0.98**;
* `total_rooms` и `total_bedrooms` — **0.93**;
* `total_rooms` и `households` — **0.92**;
* `population` и `households` — **0.91**;
* `total_bedrooms` и `population` — **0.88**;
* `total_rooms` и `population` — **0.86**.

Это показывает наличие мультиколлинеарности: некоторые признаки содержат похожую информацию.

Также наблюдается сильная отрицательная корреляция между `longitude` и `latitude` — **-0.92**. Эти признаки характеризуют географическое положение районов, поэтому они не удалялись автоматически только на основании корреляции.

---

## Сокращённая модель

После анализа корреляций была создана модель с сокращённым набором признаков.

В неё вошли:

```text
longitude
latitude
housing_median_age
total_rooms
median_income
ocean_proximity
```

Результаты сокращённой модели:

| Метрика |         Значение |
| ------- | ---------------: |
| MAE     |        52 663.96 |
| MSE     | 5 266 354 964.82 |
| RMSE    |        72 569.66 |
| R²      |           0.5981 |

---

## Сравнение моделей

| Модель   |       MAE |      RMSE |     R² |
| -------- | --------: | --------: | -----: |
| Baseline | 50 670.49 | 70 059.19 | 0.6254 |
| Reduced  | 52 663.96 | 72 569.66 | 0.5981 |

После сокращения набора признаков:

* MAE увеличился;
* RMSE увеличился;
* R² уменьшился.

Таким образом, сокращённая модель показала более низкое качество на тестовой выборке.

## График предсказаний

Был построен график зависимости предсказанных значений от истинных значений.

Точки в целом имеют восходящее направление, что показывает наличие связи между реальной и предсказанной стоимостью жилья.

При этом наблюдается заметный разброс точек, поэтому модель не даёт одинаково точные прогнозы для всех районов.

---

## Анализ остатков

Также был построен график распределения остатков.

Большая часть остатков сосредоточена около нуля, однако распределение не является полностью симметричным и имеет выраженный правый хвост.

Наблюдаются отдельные большие положительные остатки. Это означает, что в некоторых случаях модель значительно занижает реальную стоимость жилья.

Таким образом, линейная модель не полностью описывает зависимость между признаками и стоимостью жилья.

## Финальный выбор модели

На основании результатов тестовой выборки для финальной модели выбран **полный набор признаков**.

Базовая модель показала:

* MAE = **50 670.49**;
* RMSE = **70 059.19**;
* R² = **0.6254**.

Сокращение признаков привело к ухудшению всех основных показателей качества.

Поэтому в рамках проведённого эксперимента использование полного набора признаков обеспечивает более высокое качество прогнозирования на тестовой выборке.
