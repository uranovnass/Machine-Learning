# Практическая работа — Подбор порога классификации

## Вариант B — уровень B

### 1. Цель работы

Цель работы — обучить модель классификации, получить вероятности принадлежности объектов к положительному классу, оценить качество модели с помощью ROC-AUC и PR-AUC, а также подобрать порог классификации, отличный от стандартного значения 0.5.

В работе сравниваются Accuracy, Precision, Recall и F1-score при разных порогах классификации.

---

## 2. Используемый датасет

В работе используется **Breast Tissue Dataset**.

Размер датасета:

```text
106 строк × 10 столбцов
````

Столбцы:

* `Class` — исходный класс;
* `I0`
* `PA500`
* `HFS`
* `DA`
* `Area`
* `A.DA`
* `Max.IP`
* `DR`
* `P`

В исходном датасете присутствует 6 классов:

* `adi`
* `car`
* `mas`
* `gla`
* `fad`
* `con`

Для выполнения задачи классификация была преобразована в бинарную:

* `adi` → положительный класс `1`;
* остальные классы → отрицательный класс `0`.

Пропущенных значений в датасете не обнаружено.

---

## 3. Подготовка данных

Данные были загружены из файла:

```text
../data/data.csv
```

Признаки были разделены на `X`, а целевая переменная — на `y`.

Данные разделены на обучающую и тестовую выборки:

```text
Обучающая выборка: 84 объекта
Тестовая выборка: 22 объекта
```

При разделении использовались:

```text
test_size = 0.2
random_state = 42
stratify = y
```

## 4. Обучение модели

Для классификации использована модель **Random Forest Classifier**.

Параметры:

```text
n_estimators = 100
random_state = 42
```

После обучения модели были получены не только предсказанные классы, но и вероятности принадлежности объектов к положительному классу с помощью:

```python
predict_proba()
```

---

## 5. ROC-кривая

Для оценки качества модели была построена ROC-кривая.

Полученное значение:

```text
ROC-AUC = 0.988
```

ROC-AUC показывает способность модели различать положительный класс `adi` и отрицательный класс при различных значениях порога.

Полученное значение `0.988` близко к 1, поэтому на тестовой выборке модель хорошо разделяет два класса.

---

## 6. PR-кривая

Также была построена Precision-Recall кривая.

Полученное значение:

```text
PR-AUC = 0.967
```

PR-AUC показывает качество модели с точки зрения Precision и Recall при изменении порога классификации.

Высокое значение `0.967` показывает хорошее качество обнаружения положительного класса `adi`.

---

## 7. Результаты при стандартном пороге 0.5

Сначала был использован стандартный порог:

```text
threshold = 0.5
```

Полученные результаты:

| Метрика   | Значение |
| --------- | -------: |
| Accuracy  |    0.955 |
| Precision |    1.000 |
| Recall    |    0.800 |
| F1-score  |    0.889 |

Матрица ошибок:

```text
[[17, 0],
 [ 1, 4]]
```

Таким образом:

```text
TN = 17
FP = 0
FN = 1
TP = 4
```

При пороге 0.5 модель не допустила ложноположительных ошибок, однако один объект положительного класса `adi` был пропущен.

---

## 8. Подбор порога

Для выбора подходящего порога были проверены значения от `0.10` до `0.90`.

Для каждого порога рассчитывались:

* Precision;
* Recall;
* F1-score.

Наибольшее значение F1-score среди проверенных порогов:

```text
F1 = 0.909
```

было получено при порогах от `0.15` до `0.35`.

Для дальнейшего сравнения был выбран порог:

```text
threshold = 0.15
```

---

## 9. Результаты при пороге 0.15

При новом пороге были получены следующие результаты:

| Метрика   | Значение |
| --------- | -------: |
| Accuracy  |    0.955 |
| Precision |    0.833 |
| Recall    |    1.000 |
| F1-score  |    0.909 |

Матрица ошибок:

```text
[[16, 1],
 [ 0, 5]]
```

Таким образом:

```text
TN = 16
FP = 1
FN = 0
TP = 5
```

---

## 10. Сравнение порогов

| Метрика   | Порог 0.5 | Порог 0.15 |
| --------- | --------: | ---------: |
| Accuracy  |     0.955 |      0.955 |
| Precision |     1.000 |      0.833 |
| Recall    |     0.800 |      1.000 |
| F1-score  |     0.889 |      0.909 |
| FP        |         0 |          1 |
| FN        |         1 |          0 |

При уменьшении порога с `0.5` до `0.15` Accuracy не изменилась и осталась равной `0.955`.

При этом Recall увеличился с `0.800` до `1.000`, а F1-score — с `0.889` до `0.909`.

Количество ложноотрицательных результатов уменьшилось с `1` до `0`, но появился один ложноположительный результат.

---

## 11. Итоговый вывод

В ходе работы была обучена модель Random Forest для бинарной классификации, где класс `adi` был выбран положительным, а остальные классы — отрицательными.

Модель показала высокие значения ROC-AUC (`0.988`) и PR-AUC (`0.967`), что говорит о хорошем качестве разделения классов на тестовой выборке.

Стандартный порог `0.5` был проверен и сравнён с другими значениями. При пороге `0.15` Recall увеличился до `1.000`, F1-score увеличился до `0.909`, а Accuracy сохранилась на уровне `0.955`.

Поэтому в данной работе выбран порог `0.15`. Он позволяет не допустить ложноотрицательных результатов на тестовой выборке (`FN = 0`), хотя количество ложноположительных результатов увеличилось до `1`.

Таким образом, подбор порога позволил изменить баланс между Precision и Recall и получить более высокий F1-score по сравнению со стандартным порогом `0.5`.
