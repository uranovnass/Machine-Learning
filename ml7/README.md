# Практическая работа № 7. Случайный лес

## Цель работы

Изучить алгоритм Random Forest для решения задачи регрессии, подобрать гиперпараметры модели, сравнить качество разных моделей и определить важность признаков.

## Датасет

Используется датасет `housing.csv` с информацией о жилье в Калифорнии.

Целевая переменная: `median_house_value` — медианная стоимость жилья.

## Используемые библиотеки

- `pandas` — обработка данных.
- `numpy` — вычисления.
- `matplotlib` — визуализация результатов.
- `scikit-learn` — обучение моделей и оценка качества.

## Выполненные задания

1. Загружен и изучен датасет.
2. Данные разделены на обучающую и тестовую выборки.
3. Выполнена предварительная обработка числовых и категориальных признаков.
4. Обучена модель Decision Tree Regressor.
5. Обучена модель Random Forest Regressor с параметрами по умолчанию.
6. Выполнен подбор гиперпараметров с помощью `GridSearchCV` и кросс-валидации.
7. Проведено сравнение моделей по метрикам MAE, RMSE и R².
8. Построен график важности признаков.
9. Проведён эксперимент с исключением наименее важных признаков.
10. Сформулированы выводы по результатам экспериментов.

## Метрики оценки

- **MAE** — средняя абсолютная ошибка прогнозирования.
- **RMSE** — корень из средней квадратичной ошибки.
- **R²** — коэффициент детерминации, характеризующий качество модели.

Меньшие значения MAE и RMSE указывают на меньшую ошибку. Чем ближе R² к 1, тем лучше модель объясняет изменчивость целевой переменной.

## Вывод

В ходе практической работы были изучены принципы работы случайного леса и влияние гиперпараметров на качество регрессионной модели. С помощью GridSearchCV выполнен подбор параметров, проведено сравнение моделей и исследована важность признаков.

Окончательный выбор модели сделан на основе результатов тестирования по метрикам MAE, RMSE и R². Эксперимент с сокращением признаков позволил оценить, как их количество влияет на качество прогнозирования.
