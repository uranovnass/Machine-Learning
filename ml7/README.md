## 1. Описание проекта

Проект посвящён построению и исследованию моделей машинного обучения для прогнозирования медианной стоимости жилья в Калифорнии.

В работе используется датасет `housing.csv`, содержащий географические, демографические и жилищные характеристики районов Калифорнии.

Основная задача — обучить регрессионные модели, сравнить их качество, подобрать гиперпараметры случайного леса и определить, какие признаки вносят наибольший вклад в прогнозирование.

В рамках экспериментов рассматриваются:
- дерево решений;
- случайный лес с параметрами по умолчанию;
- случайный лес с подобранными гиперпараметрами;
- случайный лес на сокращённом наборе признаков.

## 2. Цель и задачи

### Цель

Изучить алгоритм Random Forest для регрессии, освоить подбор гиперпараметров и исследовать влияние признаков на качество прогнозирования.

### Задачи

1. Загрузить и изучить датасет.

5. Реализовать предварительную обработку числовых и категориальных данных.
6. Обучить дерево решений и случайный лес с параметрами по умолчанию.
7. Выполнить подбор гиперпараметров с помощью GridSearchCV.
8. Сравнить модели по MAE, RMSE и R².

## 6. Предварительная обработка данных

### 6.1. Разделение признаков и целевой переменной

- `X` — все входные признаки, кроме `median_house_value`.
- `y` — целевая переменная `median_house_value`.

### 6.2. Разделение на выборки

Для эксперимента используется разделение:
- 80% — обучающая выборка;
- 20% — тестовая выборка.

Параметр `random_state=42` позволяет воспроизводить разделение при повторном запуске с теми же данными и настройками.

### 6.3. Числовые признаки

Для числовых признаков применяется `SimpleImputer` со стратегией `median`, если в данных присутствуют пропущенные значения.

### 6.4. Категориальные признаки

Для `ocean_proximity` применяется:
- заполнение пропусков наиболее частым значением;
- One-Hot Encoding через `OneHotEncoder(handle_unknown='ignore')`.

Кодирование преобразует категории в числовое представление, пригодное для модели.

### 6.5. Предотвращение утечки данных

Предобработка включена в `Pipeline` и обучается на обучающих данных. Тестовая выборка используется только для итоговой оценки качества моделей.

При подборе гиперпараметров предобработка выполняется внутри пайплайна в рамках кросс-валидации.

## 7. Используемые алгоритмы

### 7.1. Decision Tree Regressor

Дерево решений последовательно разбивает данные на группы, выбирая условия, которые помогают прогнозировать числовую целевую переменную.

Преимущества:
- простота;
- возможность анализа структуры дерева;
- способность моделировать нелинейные зависимости.

Недостаток: одиночное дерево может переобучаться и быть чувствительным к изменениям данных.

### 7.2. Random Forest Regressor

Случайный лес объединяет множество деревьев решений. Каждое дерево обучается на случайной выборке обучающих данных и рассматривает случайные подмножества признаков при выборе разбиений.

Для регрессии итоговый прогноз формируется путём усреднения прогнозов деревьев.

Преимущества:
- способность моделировать сложные зависимости;
- снижение зависимости результата от одного дерева;
- возможность оценивать важность признаков.

Недостатки:
- более высокие требования к вычислительным ресурсам;
- меньшая интерпретируемость по сравнению с одним деревом;
- важность признаков не доказывает причинно-следственную связь.

### 7.3. GridSearchCV

`GridSearchCV` перебирает заданные комбинации гиперпараметров и оценивает их с помощью кросс-валидации.

В работе исследуются следующие параметры:

| Гиперпараметр | Проверяемые значения | Назначение |
|---|---|---|
| `n_estimators` | 50, 100 | Количество деревьев |
| `max_depth` | `None`, 20 | Максимальная глубина дерева |
| `min_samples_leaf` | 1, 2 | Минимальное количество объектов в листе |

Используется трёхблочная кросс-валидация (`cv=3`) и критерий `neg_root_mean_squared_error`.

Поскольку Scikit-learn использует отрицательное значение для функции потерь в режиме максимизации, наилучшее значение критерия соответствует меньшей ошибке RMSE.

Поиск ограничен заданной сеткой параметров. Он не гарантирует нахождения глобально оптимальной конфигурации среди всех возможных вариантов.

## 8. Оценка качества моделей

Для сравнения используются три метрики.

### MAE — Mean Absolute Error

Средняя абсолютная разница между фактическими значениями и прогнозами.

Чем меньше MAE, тем меньше средняя абсолютная ошибка. Единицы измерения соответствуют единицам целевой переменной.

### RMSE — Root Mean Squared Error

Корень из средней квадратичной ошибки. Сильнее реагирует на большие ошибки прогнозирования.

Чем меньше RMSE, тем лучше результат по этой метрике.

### R² — коэффициент детерминации

Характеризует качество модели относительно прогноза средним значением целевой переменной.

- Значение около 1 указывает на хорошее соответствие модели данным.
- Значение около 0 означает, что модель примерно не превосходит базовый прогноз средним значением.
- Отрицательное значение означает, что модель на тестовых данных хуже такого базового прогноза.

Ни одна метрика не должна рассматриваться отдельно от остальных.

## 9. Анализ важности признаков

После обучения лучшей модели Random Forest извлекаются значения `feature_importances_`.

Они используются для ранжирования обработанных признаков по их вкладу в снижение неоднородности при разбиениях деревьев.

Поскольку категориальный признак после One-Hot Encoding превращается в несколько столбцов, для сравнения исходных признаков необходимо объединить важности соответствующих преобразованных столбцов.

Далее:
1. Строится график важности признаков.
2. Признаки ранжируются по важности.
3. Выбирается подмножество признаков для дополнительного эксперимента.
4. Модель повторно обучается на сокращённом наборе.
5. Результаты сравниваются с полной моделью.

Важно: встроенная важность Random Forest может быть смещена в пользу определённых типов признаков. Она не доказывает, что признак вызывает изменение стоимости жилья. Для более глубокого анализа можно дополнительно использовать permutation importance.

## 10. Эксперимент с сокращением признаков

В эксперименте исключаются признаки с наименьшей рассчитанной важностью.

После сокращения:
- создаются новые обучающие и тестовые данные;
- формируется новый `ColumnTransformer`;
- обучается модель Random Forest;
- вычисляются MAE, RMSE и R²;
- результаты сравниваются с полной моделью.

Сокращение количества признаков не обязательно улучшает качество. Результат определяется фактическими метриками на тестовой выборке.

Для корректного сравнения обе модели должны оцениваться на одинаковом разделении данных.
